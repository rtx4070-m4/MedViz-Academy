## ✨ Overview

**MedViz Academy** is a standalone browser-based learning and analytics
application designed around a healthcare data-to-insight workflow.

It combines:

-   🧪 **Data → Insight Lab**
-   🧭 **Visual Decision Guide**
-   🏥 **Healthcare Analytics**
-   🧠 **Insight Engine**
-   🎓 **Research + AI Tutor**
-   📚 **Concept learning**
-   ⚠️ **Common visualization mistakes**
-   🚀 **Golden Workflow**
-   📄 **Research/report-building tools**
-   🎤 **Exam and viva-oriented learning**

The application is intentionally delivered as a self-contained HTML
application, making it easy to run locally or publish with **GitHub
Pages**.

> **Important:** The current "AI" functionality is a **browser-local,
> rule-based AI-style analyst/tutor**. It does not connect to an
> external LLM, literature database, clinical decision system, or
> backend service.

------------------------------------------------------------------------

## 🧩 Product Philosophy

MedViz Academy follows a simple healthcare analytics learning chain:

``` text
DATA
  ↓
UNDERSTAND
  ↓
VISUALIZE
  ↓
ANALYZE
  ↓
DISCOVER
  ↓
RESEARCH
  ↓
LEARN
  ↓
EXPLAIN
  ↓
REPORT
  ↓
DEFEND
```

The goal is not merely to generate charts. The application emphasizes
the relationship between **data, context, statistical reasoning,
visualization, interpretation, research quality, and scientific
communication**.

## 🚀 Key Features

### 1. 🧪 Data → Insight Lab

Upload or paste CSV data and work through an exploratory analytics
workflow.

Capabilities include:

-   CSV upload
-   Pasted CSV input
-   Built-in hospital-style sample data
-   Automatic row and column profiling
-   Missing-value assessment
-   Duplicate checks
-   Data-quality scoring
-   Variable intelligence
-   Analytical question selection
-   Visualization recommendations
-   Automatic visual rendering
-   Interpretation of the selected visual

------------------------------------------------------------------------

### 2. 🧭 Visual Decision Guide

A question-first guide for choosing an appropriate visualization.

Examples include:

  Analytical question              Suggested visual
  -------------------------------- --------------------------
  Compare categories               Bar chart
  Show a trend                     Line chart
  Show composition                 Pie / donut
  Examine a relationship           Scatter plot
  Explore many categories          Packed bubbles / treemap
  Show matrix patterns             Heat map
  Explore geographic information   Maps

The emphasis is on choosing a visual because it answers a question---not
because it looks attractive.

------------------------------------------------------------------------

### 3. 🏥 Healthcare Analytics

The analytics area brings together several common healthcare/statistical
analysis patterns, including:

-   KPI-style summaries
-   Epidemiological calculations
-   Independent t-test
-   Chi-square test
-   One-way ANOVA
-   Correlation
-   Simple linear regression
-   Confusion matrix
-   ROC/AUC
-   IQR-based outlier analysis
-   Anomaly detection

------------------------------------------------------------------------

### 4. 🧠 Insight Engine

The Insight Engine focuses on moving beyond "here is a chart" toward
"what does this mean?"

Included concepts/features include:

-   Insight Detective
-   Chart Doctor
-   Why this chart?
-   Automated narrative
-   Drill-down
-   Before vs. after comparison
-   Interactive filtering

------------------------------------------------------------------------

### 5. 🎓 Research + AI Tutor

The research-oriented learning environment includes:

-   Research Mode
-   Exam Mode
-   Viva Mode
-   Research/report generation
-   Dashboard export concepts
-   Healthcare storytelling
-   AI-style analyst interaction
-   Research-quality self-auditing

The research-quality checker encourages attention to:

-   Study objectives
-   Assumptions
-   Effect sizes and confidence intervals
-   Visualization suitability
-   Limitations
-   Reproducibility
-   Appropriate causal language

------------------------------------------------------------------------

## 🔒 Privacy & Data Handling

The application is designed around browser-local interaction.

The current interface explicitly communicates that the dataset stays in
the browser session.

That means the project does **not** require a server just to load and
explore a CSV.

However:

> Do not upload real patient-identifiable or otherwise sensitive
> healthcare data to an environment unless your organization has
> explicitly approved that workflow and the required privacy/security
> controls are in place.

This project should be treated as an **educational/exploratory
application**, not as a clinical data platform.

------------------------------------------------------------------------

## ⚠️ Clinical and Statistical Disclaimer

**MedViz Academy is an educational and exploratory tool. It does not
replace clinical judgment, a validated statistical software package,
formal statistical review, or a prespecified research analysis plan.**

For epidemiological analysis, users should independently verify:

-   Numerator
-   Denominator
-   Target population
-   Time period
-   Case definition
-   Study design
-   Missing-data handling
-   Appropriate statistical assumptions
-   Effect sizes and uncertainty
-   Clinical relevance

Results generated by this educational application should be
independently validated before being used in research, publication,
operational decisions, or clinical settings.

## 📁 Recommended Repository Structure

The recommended GitHub repository is:

``` text
MedViz-Academy/
│
├── index.html
├── README.md
├── LICENSE
├── .gitignore
│
└── assets/
    ├── project-banner.svg
    │
    └── screenshots/
        ├── 01-data-insight-lab.png
        ├── 02-healthcare-analytics.png
        ├── 03-research-ai-tutor.png
        └── 04-insight-engine.png
```

### Why this structure?

-   `index.html` → GitHub Pages entry point
-   `README.md` → project documentation
-   `LICENSE` → legal open-source terms
-   `.gitignore` → keeps unnecessary local files out of Git
-   `assets/project-banner.svg` → GitHub project branding
-   `assets/screenshots/` → visual documentation

As the project grows, a more modular architecture can be introduced:

``` text
MedViz-Academy/
├── index.html
├── README.md
├── LICENSE
├── assets/
├── css/
│   └── styles.css
├── js/
│   ├── app.js
│   ├── analytics.js
│   ├── visualizations.js
│   └── research.js
├── data/
│   └── sample/
└── docs/
```

For the **current version**, keeping the application as one standalone
`index.html` is reasonable.

## ▶️ Run Locally

### Option 1 --- Open directly

Download or clone the repository and open:

``` text
index.html
```

in a modern browser.

### Option 2 --- Run a local server

From the repository directory:

``` bash
python -m http.server 8000
```

Then open:

``` text
http://localhost:8000
```

A local server is useful when developing the project further and
provides behavior closer to a hosted web environment.

## 🌐 Deploy with GitHub Pages

1.  Create a GitHub repository named:

    ``` text
    MedViz-Academy
    ```

2.  Upload:

    ``` text
    index.html
    README.md
    LICENSE
    .gitignore
    assets/
    ```

3.  Open:

    **Settings → Pages**

4.  Under **Build and deployment**, choose:

    ``` text
    Deploy from a branch
    ```

5.  Select:

    ``` text
    Branch: main
    Folder: / (root)
    ```

6.  Save.

GitHub will publish the site using `index.html` as the entry point.

6.  Apply common statistical reasoning patterns.
7.  Recognize common visualization mistakes.
8.  Build a defensible research workflow.
9.  Communicate analytical findings clearly.
10. Prepare for research examinations and viva-style questioning.
